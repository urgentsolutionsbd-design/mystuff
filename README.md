# RelentlessGig — first website concept

A responsive editorial marketing website inspired by the layout language in the reference screenshots: warm neutral palette, oversized serif typography, asymmetric imagery, generous whitespace and layered artwork.

## Files
- `index.html` — site structure and content
- `styles.css` — responsive visual design
- `script.js` — mobile navigation, reveal animations and demo form feedback

## Preview
Open `index.html` in a browser. Internet access is only used to load Google Fonts; the artwork itself is built with CSS/SVG and works locally.

## Before launch
1. Replace placeholder copy with final service descriptions and bio.
2. Connect the contact form to Formspree, Netlify Forms, a CRM or custom backend.
3. Add your domain, analytics and SEO/social metadata.
4. Optionally replace the generated abstract art with original photography or campaign artwork.
Website deployment enabled.
